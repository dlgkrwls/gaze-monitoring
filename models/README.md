# models/

This directory holds the face-detection model used by the demo.

## Included

- `face_detection_yunet_2023mar.onnx` — the public [OpenCV YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) face detector. This file is tracked in the repository and requires no separate download.

## Not included

The gaze-estimation model is **not** stored here. It lives in [`weights/`](../weights/README.md) and is not distributed with this repository — see that README for details.
